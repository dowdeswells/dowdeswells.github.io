I've decided to develop an application hosted on Azure. Developed, or should I say, co-developed with an I agent and featuring some form of agentic processing.

The application is an expenses tracker. Something which has become slightly more pertinent given recent events.

At work I was using Copilot installed into Rider for.NET development.

But upon researching what is available, it has become apparent that a more simple tool is needed with less clutter, something in a terminal.
This is provided by py.dev 
It integrates simply with DeepSeek, just an environment variable with the deep seek API key
It seems pretty good so let's start there.

My goal is to develop the application, and also to develop the processes via which I will employ the AI agent to help me code.
